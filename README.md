# 🎮 Timepass_Games by Priyanshu

A collection of fun and interactive small games built with **JavaScript**. This project is designed to showcase simple game mechanics and logic using pure JS. It's a great way to pass the time with some classic games!

---

## 🕹️ Games Included

1. **Colour Guess**: Guess the correct color from a set of choices.
2. **GuessNum**: A number guessing game where the player has to guess a randomly generated number.
3. **Snake Ladder**: A digital version of the classic board game Snake and Ladder.
4. **Tetris**: The classic Tetris game where you fit falling blocks to complete rows.
5. **TikTac**: A simple Tic-Tac-Toe game for two players.

---

## 🛠️ Technologies Used

- **HTML** for basic structure
- **CSS** for styling
- **JavaScript** for game logic and interactivity

---

## 🚀 Features

- Simple and intuitive UI
- Interactive gameplay
- Built with Vanilla JavaScript (no frameworks or libraries used)

---

## 📄 How to Play

1. Clone or download the repository.
2. Open the game files in a browser to start playing.
3. Follow the on-screen instructions for each game.
